# Пиццерия — редактор образовательной игры

Версия 1.2.0. Статический редактор без сборки и сторонних библиотек. Откройте **index.html** в современном браузере или разместите файлы на GitHub Pages.

## Размещение в galmizmaria-beep/pizza

1. Распакуйте `pizza-editor-github.zip`.
2. Откройте https://github.com/galmizmaria-beep/pizza → **Add file → Upload files**. Загрузите содержимое архива в корень репозитория, затем **Commit changes**.
3. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, нажмите **Save**.
4. После публикации редактор будет доступен по адресу https://galmizmaria-beep.github.io/pizza/ .

## Работа

- Стартовый проект содержит шесть кликабельных рецептов, четырнадцать ингредиентов и пять разных типов заданий.
- Панель ограничена высотой предпросмотра и прокручивается внутри. Редактируется один выбранный заказ, ингредиент или вопрос, дополнительные настройки сворачиваются. «Тестировать» запускает полный игровой цикл с начала.
- Ингредиенты можно нажимать или перетаскивать на пиццу. В задании на порядок работают стрелки и перетаскивание карточек.
- Клиент, меню, панель ингредиентов, пустой стол, тесто и слои продуктов перемещаются в режиме редактирования; видимые угловые маркеры меняют размер. Во вкладке «Кухня и раскладка» слои заранее размещаются на тесте; в игре они появляются после правильных ответов. Можно добавлять копии продуктов. Чашки остаются в панели выбора, на тесто попадают отдельные изображения продуктов без посуды.
- Цвет кнопок и букв, шрифт, высота, боковые отступы, скругление и свечение настраиваются в разделе «Кнопки и стиль». Для вариантов ответа предусмотрены отдельные цвета.
- Встроенные звуковые эффекты работают без файлов. Для шести готовых рецептов встроены отдельные русские аудиозаписи; музыка и эффекты приостанавливаются на время речи. Для изменённых текстов используется русский голос браузера или загруженная автором запись. Звук запускается только после действия пользователя и отключается в разделе «Звуки».
- «Сохранить проект» скачивает JSON со встроенными медиа. «Загрузить проект» восстанавливает проект. IndexedDB хранит локальное автосохранение.
- «Скачать HTML» создаёт отдельную автономную игру. Интерфейс редактора, история, загрузчики и авторский footer в игру не включаются.

## Кнопка «Облегчить код» и Genially

Кнопка создаёт актуальный экспорт, хранит повторяющиеся медиа только один раз, исключает неиспользуемые ингредиенты и задания, уменьшает большие статичные изображения до максимальной стороны 1100 px и сжимает в WebP с качеством 0.76, если результат меньше. Прозрачность сохраняется. GIF и аудио остаются исходными. Размер сравнивается в байтах, и более тяжёлая версия никогда не заменяет исходную. Код обработки трансформаций и CSS рамок исключаются из игрового экспорта.

«Скопировать для Genially» копирует iframe со встроенным `srcdoc`, без ссылок на GitHub. Вставьте его в блок внешнего контента/HTML, допускающий iframe с srcdoc и JavaScript. Если конкретный редактор Genially удаляет srcdoc или ограничивает длину кода, разместите скачанный **pizzeria-game.html** на HTTPS-хостинге и вставьте iframe с URL этого файла. Такая копия игры фиксирует проект на момент экспорта. Совместимость вставки с текущим интерфейсом Genially в этой среде не проверена.

После изменений проекта экспорт пересоздаётся. При недоступном буфере обмена откроется выделенный код для ручного копирования.

## Реализованные ограничения первой версии

Реализованы 11 вкладок, несколько заказов, пять типов заданий, строгая привязка заданий к ингредиентам, жизни, общий таймер (истечение → поражение), баллы, бонусы, комбо, аудио, загрузка медиа и экспорт.

ТЗ шире этой версии: полноценные переводы всех перечисленных языков, поиск/избранное большого каталога шрифтов, таймеры на заказ/задание, ограничения попыток, отдельные анимации печи и входа клиентов, GIF-перекодирование и полная система произвольных объектов пока не реализованы. Системные кнопки переведены на русский и английский; другие предложенные языки используют явно указанный English fallback, RTL включается для ar/he/fa. GIF сохраняются анимированными без перекодирования.

## Проверка

`node tests/runtime.test.cjs` проверяет пять типов заданий, жизни, победу, поражение, меню и озвучивание выбранного заказа, слои без посуды, перетаскивание и маркеры размера, встроенные эффекты, все разделы редактора, валидацию и экранирование JSON. Это проверка логики в модели DOM; визуальная проверка в настоящем браузере и вставка в Genially необходимы отдельно.

## Файлы

- `index.html`, `editor.css`, `editor.js` — редактор.
- `game.js` — игровой runtime и стили игры.
- `starter-assets.js` и `starter-assets-*.js` — изображения, встроенные как Data URI для работы даже через file://.
- `ASSETS.md` — анализ и назначение исходных ассетов.
- `GENERATED_ASSETS.md` — новые изображения и промпты генерации.
- `assets/*.png` — отдельные готовые изображения для скачивания.

Проекты версий 1.0 и 1.1 мигрируют в 1.2: вопросы и авторские тексты сохраняются, добавляются новые продукты и рецепты, старый стол заменяется пустым и исправляется исходное положение клиента.

## Изменения 1.2

- В начале приготовления стол пуст. Тесто появляется после выбора основы и правильного выполнения её задания.
- «Рецепт» показывает ингредиенты текущего заказа с отметками готовности. Выбор другой пиццы вынесен в отдельную кнопку.
- Панель продуктов перемещается и меняет размер рамкой в «Кухня и раскладка»; число колонок и высота ячеек настраиваются отдельно.
- «Большое комбо» содержит 12 заданий, «Суперкомбо» — 14. В «Меню и пиццы» кнопка «Порция с отдельным заданием» добавляет новый продукт с независимым вопросом; число порций не ограничено.
- Новые изображения: ветчина, курица, сладкий перец, кукуруза, ананас, лук, две готовые пиццы. Записи заказов лежат в `assets/audio/`; описание — `NARRATION.md`.
